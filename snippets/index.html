Pour faire le ménage en profondeur sur votre serveur Docker et libérer de l'espace disque en supprimant les conteneurs arrêtés, les réseaux inutilisés, les images non attachées et le cache de build.

docker system prune -a --volumes -f

Ajoutez cet alias dans votre fichier ~/.bashrc pour pouvoir tout mettre à jour d'une seule commande rapide.

alias updateall='sudo apt update && sudo apt upgrade -y && sudo apt autoremove -y && sudo apt autoclean'

Après l'avoir ajouté, rechargez votre terminal avec source ~/.bashrc.

Un bloc serveur minimaliste pour forcer toutes les requêtes HTTP (port 80) de tous vos domaines vers leur équivalent HTTPS (port 443).

server {
    listen 80 default_server;
    listen [::]:80 default_server;
    server_name _;
    return 301 https://$host$request_uri;
}
